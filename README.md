# 🏡 Airbnb Data Analysis & Price Insights

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on an Airbnb dataset to understand pricing patterns, availability trends, and neighborhood-level variations. The analysis focuses on uncovering key factors influencing listing prices and availability.

## 🎯 Objectives
- Analyze pricing distribution and detect outliers  
- Understand the impact of location and room type on pricing  
- Identify trends in availability and reviews  
- Perform feature engineering for deeper insights  

## 🛠️ Tools & Technologies
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Jupyter Notebook  

## 📊 Key Analysis Performed
- Data cleaning (handling missing values, duplicates, typecasting)  
- Univariate analysis (price distribution, availability trends)  
- Bivariate analysis (price vs location, reviews, room type)  
- Feature engineering (e.g., price per bed)  

## 📈 Key Insights
- Significant price variation across neighborhoods  
- Room type plays a major role in pricing  
- Listings with higher reviews show distinct pricing patterns  
- Availability trends indicate seasonal or demand-based patterns  

## ⚙️ Data Processing
- Removed null values and duplicates  
- Converted data types for consistency  
- Filtered extreme outliers for better analysis  

## 🚀 Outcome
- Delivered actionable insights on pricing behavior  
- Identified key drivers affecting listing prices  
- Built a structured EDA workflow for real-world datasets
